## 3. 堆叠卡片（`LAYOUT_STACKED`）交互物理与边界契约

1. **视觉层深**：依据 `ReviewSession.remaining()` 动态渲染背后叠层：`remaining >= 3` 显示 2 层底卡（共 3 层），`remaining == 2` 显示 1 层底卡，`remaining == 1`（最后一张）显示 0 层底卡（不显示幽灵卡片），`ended()` 时平滑进入总结页。
2. **跟手拖拽与微旋转**：水平拖拽位移 `dx` 时，顶卡实时跟手平移并按 `clamp(dx / width * 9.5°, -9.5°, +9.5°)` 轻微旋转；底层卡片随 `min(1, |dx| / threshold)` 同步放大上浮。
3. **方向语义、阈值与回弹**：
   - **右滑 = 记得**（左上显示松墨绿 `记得 →` 印章，过阈值触发轻触感反馈）；
   - **左滑 = 忘记**（右上显示赭陶色 `← 忘记` 印章，过阈值触发轻触感反馈）；
   - **提交阈值**：位移 `|dx| >= 96dp` 或同向甩动 `|dx| >= 44dp && |vx| >= 620dp/s`；未达阈值松手弹性回弹归位（`OvershootInterpolator`），减少动画模式直接归零无动画。
4. **查看答案与评分分离 + 兜底按钮（无假撤销）**：
   - 轻点卡片仅在「正面 ↔ 显示释义」之间切换，**不误触评分**；
   - 底部固定 52dp 高的 `忘记` / `记得` 兜底按钮（遵循 `Motion.press` + `Feedback`），支持单手与无障碍用户操作；不提供假撤销按钮。
5. **防重复评分 / 动画竞态与适配**：
   - `changing` 状态锁 + `expected == session.answered()` 校验 + 动画期间禁用底部按钮，防止快速双击或滑动与按钮并发触发双次评分；
   - 顶部 `🔊 朗读单词` / `⋯ 更多` 保持 ≥ `48dp × 48dp` 且与卡片拖拽区域完全隔离；长词/大字（`font_scale 1.35`）/横屏自动进入紧凑排版与行数约束。
