## v0.6 记录（历史）


> 目标：在保留全部现有功能与业务逻辑的前提下，做一次克制、完整、有设计感的视觉升级。  
> 参考气质：Things 3 的温和留白 + Linear 的精致一致性。  
> 禁止：大面积渐变、玻璃拟态、花哨阴影、过多装饰图标、夸张动画。

## 设计方向

- 极简但不单调；温暖但不幼稚；精致但不花哨
- 看一眼就懂；点击有恰当反馈；长期使用不疲劳
- 每个页面原则上只有一个最突出的主操作
- 危险操作不与普通添加操作共用绿色主样式

统一尺寸：

- 页面水平边距：20px
- 间距：4 / 8 / 12 / 16 / 24 / 32px
- 正文：15–16px；页面标题：24–28px
- 卡片圆角 ≈ 16px；按钮圆角 12–14px；主按钮高度 48–52px

代码唯一来源：`Theme.java`。`WordUi` / `MainActivity` 不得再各维护一套色值。

## 现有视觉问题清单

1. **配色双轨**：`MainActivity` 与 `WordUi` 各有相近但不一致的色常量。
2. **深绿统计大卡**：首页 hero 抢戏，违背「一个主操作」。
3. **按钮过大且同级**：录词 / 新建等权双主按钮，图标偏多。
4. **卡片过厚**：elevation、圆角、内边距叠加，信息层级扁平。
5. **底栏玻璃感**：半透明高 elevation，偏离克制方向。
6. **设置二级导航粗**：「返回设置目录」整行大按钮（阶段五处理）。
7. **状态栏不一致**：部分页深绿状态栏，主页浅底 + light icons。

## 首页信息架构（目标）

1. 日期 + 标题 + 待复习数量（去掉深绿大统计卡）
2. 紧凑工具行：录词（线框/文字）+ 新建（次要）
3. 待复习任务：主操作「开始复习」+ 次要「任意复习」
4. 之后安排：紧凑列表行
5. 课程 Lesson 薄卡片
6. 已完成折叠区
7. 底栏：实心浅底 + soft 选中态，降低高度与 elevation

## 微交互约定

- 按下：轻微缩放 / 颜色变化，约 120–160ms
- 页面进入：淡入或轻位移，约 180–220ms
- 遵守系统 Animator Duration Scale 与应用内 `motion` 开关
- 加载 / 禁用 / 成功 / 错误均有清楚反馈（沿用现有 Feedback / Toast）
